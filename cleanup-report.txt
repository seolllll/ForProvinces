[3] Zustand Store 정리 — src/store/mapStore.ts

제거된 항목 (4개):

  State:
  - selectedPerformanceId: string | null
    이유: 공연 상세 선택 state. 현재 상세 뷰는 PerformanceSidebar 내부
          로컬 state(selectedPrfm)로 관리하므로 전역 store 불필요.

  - performances: PerformanceSummary[]
    이유: 구 Performance 테이블 기반 공연 목록 state.
          setPerformances()와 함께 어디서도 호출되지 않음.

  Action:
  - selectPerformance(performanceId): void
    이유: selectedPerformanceId를 세팅하는 액션. 해당 state 제거로 함께 삭제.

  - setPerformances(performances): void
    이유: performances state를 세팅하는 액션. 해당 state 제거로 함께 삭제.

  Import:
  - PerformanceSummary, Category import 제거
    이유: 제거된 state의 타입으로만 사용됨.

  - export type { Category } 제거
    이유: Category 타입 자체가 types/index.ts에서 삭제됨.

  closeSidebar 단순화:
  - 기존: set({ isSidebarOpen: false, selectedVenueId: null, selectedPerformanceId: null })
  - 변경: set({ isSidebarOpen: false, selectedVenueId: null })

제거된 함수 (3개):

  - debounce<T>()
    이유: CLAUDE.md에 지도 이동 시 debounce 처리가 명시되어 있으나,
          현재 구현은 bounds_changed 이벤트를 사용하지 않음
          (초기화 시 전체 1회 fetch 전략으로 설계됨). 미사용.

  - formatDate(dateStr)
    이유: PerformanceCard.tsx 전용. 해당 파일 삭제로 미사용.
          KOPIS 날짜 데이터는 이미 "YYYY.MM.DD" 형식 문자열로 저장되므로
          변환 불필요.

  - formatDateTime(dateStr)
    이유: 구 PerformanceDetail.tsx(Ticketing.openAt ISO 포맷용)에서 사용하던 함수.
          신규 PerformanceDetail.tsx는 relates(예매처 링크)만 렌더링하므로 미사용.

유지된 함수 (1개):

  - cn(...inputs)
    이유: clsx + tailwind-merge 결합. 전체 UI 컴포넌트에서 광범위하게 사용.
